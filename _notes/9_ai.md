# AI

Vercel AI SDK AI Elements + useChat

```sh
npx ai-elements@latest add conversation message prompt-input
```

ai: Vercel AI SDK，目前只用它的类型定义（消息格式），以后接真实 AI 时用它的功能
streamdown 和 4 个插件: 渲染 AI 回复里的 Markdown，处理“流式输出到一半”的情况
cmdk: prompt-input 里可搜索的下拉菜单
nanoid: 生成附件等的临时 ID
use-stick-to-bottom: 消息列表自动滚动到底部
